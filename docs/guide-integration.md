# 引路分支接入记录

用户已选择：使用已有视觉 API。

## 尚需提供的配置

- API 提供商和请求地址。
- 支持图片输入的模型名称。
- 本机密钥所在的配置文件路径或环境变量名（不在聊天、源码、日志中放密钥）。

在配置明确前，本分支不假定 OpenAI、Claude、Gemini 或其他协议，不接入替代模型。
现有眼镜项目提供照片采集与传输，没有已配置的环境识别服务。原 assistant 使用系统语音，产品不得调用该助手作为回退。

## 已确定的接口边界

文件所有权：`product_features/guide/` 与对应测试；通过 `register(app)` 接入产品。
与其他功能分支共用 Context、记录接口、设备只读状态；视觉请求不进入串口线程。
照片由用户主动选择或主动拍摄后发起识别；显示采集时间和识别结果，不把旧图当成当前环境。
失败、超时、无结果均明确显示无法识别，不据此推断道路可通行。
模型输出只用于环境描述，不直接变成外骨骼力矩命令。

## 后续验收

1. 连接用户指定 API，用一张获准发送的真实照片验证请求与响应。
2. 验证鉴权失败、限流、超时、图片不完整与旧图的处理。
3. 连接眼镜采集流程；不调用系统语音合成。
4. 力觉引导是后续独立的真机验证项目；原方案中的力矩数值不能当作已验证安全参数。

本分支当前只完成接口与验收约定，环境识别和实际引路尚未实现。
