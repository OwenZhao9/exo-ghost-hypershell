## 已确定的接口边界

文件所有权：`product_features/guide/` 与对应测试；通过 `register(app)` 接入产品。
与其他功能分支共用 Context、记录接口、设备只读状态；视觉请求不进入串口线程。
产品页通过 `--glasses-dir` 只读列出该目录中的 JPEG。用户主动点击单张照片后，
服务才向 EvoMap Gateway 发送图像；页面显示本机文件时间和识别结果，不把旧图当成当前环境。
失败、超时、无结果均明确显示无法识别，不据此推断道路可通行。
模型输出只用于环境描述，不直接变成外骨骼力矩命令。

## 独立连续拍照 Demo

`feat/glasses-demo-GPT` 在本分支之上增加可选的演示采集器。只有产品服务显式指定
`--glasses-bin`、`--glasses-unit` 和 `--guide-demo-upload`，并由人在页面点击开始后，
才会顺序拍照；识别线程按拍摄顺序将新照片送到 EvoMap，下一张拍照可与上一张识别同时进行。每轮最多 10 张，连续失败 3 次停止；每张都保留拍摄时间，
结果只表示画面哪一侧看起来较空。暗光桌面照片实测输出“无法判断”，不能用于真实导盲。
2026-09-23 真机连续采两张，采集耗时 11.5 秒、11.1 秒；一次识别耗时 10.6 秒。
四条真人语音录音尚未提供或验证，因此本分支没有声音输出，也没有系统语音合成回退。
演示页面将最新照片排在最上方，旧照片及对应判断继续保留；识别完成后在原卡片叠加方向状态，以及 EvoMap 返回且通过坐标校验的可见物体框。原始 JPEG 不改写。文字和标注元数据保存在本地产品数据库，照片仍在原眼镜目录，页面重开和服务重启后可恢复列表。停止后未发出的排队照片不再上传；已发出的请求可以完成。
