# exo-ghost 项目规则（Hypershell X MaxS 外骨骼控制）

## 1. 任何力都必须慢慢加，绝不允许突然的力

用户 2026-09-22 明确要求：**以后任何"给力 / 抬腿 / 保持 / 测试"类要求，都必须缓慢、渐进地施加，不允许突然的力矩或快速动作。** 原因：穿戴调试时突然的力会伤人。这条优先级高于"演示效果""响应快"之类的任何考虑。

具体做法（已在代码里成为默认值，改参数前先想清楚）：
- 力矩斜坡（`bridge.set_ramp`）：直接力矩 `torque/up/down` **1 Nm/s**，位置保持 `hold` 1.5 Nm/s，阻尼/助力 3 / 2 Nm/s；穿戴档（`--profile wearing`）在此基础上**再减半**。全局上限由服务的 `--ramp` 控制，默认 3。
- 位置保持的目标角速度（`hold --slew`）：**默认 15 °/s**（60° 走 4 秒）；穿戴时不超过 10 °/s。
- 首次施力先用小值试（力矩 ≤ 0.5 Nm、角度变化 ≤ 20°），确认方向和手感后再加大。
- 穿戴时力矩上限 1.5 Nm，未经用户明确要求不得提高；桌面软限幅 2.0 Nm，固件硬限 7.5 Nm。
- 恒定力矩命令必须带到期时间（`--seconds`），到期自动归零，禁止无限期顶着。
- 不允许用大 ramp（如以前的 12 Nm/s）做"快速甩动"的演示，除非用户当次明确要求并且设备不在人身上。

## 2. 方向约定（用户现场确认）
- 两腿**向上抬** = 左腿负、右腿正（`T,-x,+x`）；向下 = 左正右负。代码常量 `control/policies.py: UP_SIGN`。
- 每条腿自身：+力矩 → +角速度 → +角度（同号），所以 `τ = -c·ω` 在两腿都是阻尼。

## 3. 穿戴前检查（每次）
1. 开机（短按 + 长按）后等 **30 秒**，确认腿板在线、静默期结束、支架不再自检快动。
2. 服务用 `--profile wearing` 启动（加速度 / 陀螺 / 倾角急停 + 10 分钟上限）。
3. 从 `zero` 开始 → `resist` 增益 0.3 → 感觉正常再逐步调整；`assist` 增益 ≤ 0.2、上限 ≤ 0.8。
4. 急停手段：页面大红键 / `ctl estop` / Ctrl-C / 拔 USB（固件 115 ms 清零）。操作者手要能立刻够到其中一个。

## 4. 设备已知行为
- 腿板掉线（关节全 0）：机器上短按 + 长按电源键即可恢复，不用拔线；恢复后 15 秒静默期。
- 设备静止几分钟会自行"卡住/重启"，原因未知（疑似闲置待机或电量），已问 Hypershell 待答复。
- **上电基础力矩**：开机后髋关节有一个很小的向上保持力（关机即消失），会叠加在我们的力矩上。量级小，不影响穿戴安全，但做功/对照数据要减掉它（见 docs/protocol.md）。
- Mac USB-C 直连不行（PD 协商导致掉线），必须经 hub。
- 不要让电机长时间顶在机械限位上出力：2026-09-22 18:49–18:53 两腿以 1.5 Nm 顶住限位约 3 分钟后腿板掉线（疑似过流/过热保护）。恒定力矩到达限位后应降到 ≤ 0.5 Nm 或改用位置保持。
