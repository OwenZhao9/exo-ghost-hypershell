# Ghost 产品界面参考

本文件记录 `dashboard/product/` 的视觉取舍。参考公开的官方产品说明，只借鉴信息组织方式；没有复制页面代码、截图、字体或图标。

| 参考 | 可借鉴的做法 | Ghost 中的落实 |
| --- | --- | --- |
| [Oura App：Today / Vitals / My Health](https://support.ouraring.com/hc/en-us/articles/360058599753-How-to-Use-the-Oura-App) | 首屏先展示当天最相关的状态，历史趋势另设入口；数据不足时明确说明。 | 总览先显示当前设备数据状态；记录统计与档案分开。来源缺失写“来源待确认”。 |
| [Garmin Connect：自定义首页](https://support.garmin.com/en-AU/?faq=35qboQSvKC2WpKkTaDaRP7) | 区分主要关注的数据与一眼可读的摘要。 | 三项已确认的穿戴记录统计集中为一条数据带，四个功能入口按任务排列。 |
| [DJI Fly：飞行状态](https://www.dji.com/dji-fly) | 操作设备时让连接与运行状态保持可见，关键参数和停止动作位置固定。 | 工作区顶部持续显示设备数据连接；运动页把模式、强度、松劲/急停和实时曲线放在同一条操作路径。 |

视觉采用深色底、浅色文字和亮绿色重点，延续本地展示网页的 Ghost 配色。功能页使用两列任务卡，手机上改为单列和横向导航。按钮的禁用状态继续由现有设备就绪与只读条件决定；样式不能充当安全确认。

实时曲线只绘制当前设备服务新收到的帧。没有数据时保留空图和等待提示。展示网页使用静态界面结构示意，不嵌入私人记录或虚构采样数字。
