# Hypershell X MaxS 串口协议与实测标定（固件 2.9.99.1）

## 连接（实测 2026-09-22）
- 芯片：Silicon Labs **CP2102N** USB-UART 桥（VID 0x10C4 / PID 0xEA60），macOS 自带 AppleUSBSLCOM 驱动，设备名 `/dev/cu.usbserial-XXXX`（本机出现过 `-10`、`-1130`，随插的口变化）
- **Mac 的 USB-C 口直连不行**：Mac 会与设备协商 PD 供电（5 V / 3 A 合同，实测取电 1.75 A），设备随即切状态，CP2102N 只出现约 3 秒即掉线；先插线再开机则完全不枚举
- **经 USB hub 连接正常**（hub 下游是普通 USB 口，无 PD 协商）。展位上必须带 hub
- 上电顺序：开机（白灯常亮）→ 经 hub 插线 → `PING`
- 有几个 Mac 应用会抢新 USB 设备（Android File Transfer Agent、夸克网盘、Chrome、ChatGPT）。前两个已关闭；未证实它们是掉线原因，但连接前关掉更稳

## 串口参数
| 项 | 值 |
|---|---|
| 波特率 | 3,000,000，8N1 |
| 行结束 | `\n`（应答里 PONG 带 `\r\n`，其他 `\n`，解析按行 strip 即可） |
| 数据流 | 协议标称 200 Hz，**实测约 180 Hz**（主板 ms 时间戳中位间隔 6 ms），0 坏行 |
| 力矩续发 | 我们按 200 Hz 发 `T,l,r`，设备回 `OK,T,l,r`（忽略） |
| 看门狗 | **实测约 115 ms** 沉默后力矩清零（协议写 100 ms） |
| 力矩范围 | ±7.5 Nm 固件限幅；我们软限幅 ±2.0 Nm（演示） |

## 命令
`PING`→`PONG`；`VERSION`→`OK,VERSION,2.9.99.1`；`ENABLE`→`OK,ENABLE`（开流+使能）；`DISABLE`→`OK,DISABLE`；`T,<l>,<r>`→`OK,T,<l>,<r>`
错误：`ERR,NOT_ENABLED` / `ERR,T_FORMAT` / `ERR,UNKNOWN`

## 数据帧
`S:<ms>,<pitch>,<roll>,<yaw>,<gx>,<gy>,<gz>,<ax>,<ay>,<az>,<kPa>,<Ldeg>,<Rdeg>,<Ldps>,<Rdps>`
- ms 主板时间；pitch/roll/yaw 穿戴系欧拉角 °；gx/gy/gz 腰部陀螺 °/s；ax/ay/az 腰部加速度 g；kPa 气压；Ldeg/Rdeg 髋关节角 °；Ldps/Rdps 髋关节角速度 °/s
- **Ldps/Rdps 在猛甩时饱和到 ±3276.7**（int16/10 上限）——特征提取要按尖峰丢弃
- yaw 缓慢漂移（12 s 漂 ~3°），只可用短时差分

## 方向标定（实测，机器侧躺桌面、支架自由）
| 测试 | 结果 |
|---|---|
| 左腿 `T,+1.0,0` 1 s | Ldeg −41° → −15°，Ldps +25…+32 °/s：**+τ_L → +ω_L → +θ_L** |
| 右腿 `T,0,+1.0` 1 s | Rdeg 55° → 104°，Rdps +62 °/s：**+τ_R → +ω_R → +θ_R** |
| 手动同向摆动两腿 | L、R 读数一正一负：**左右物理镜像**（同一物理方向，符号相反） |

结论：
1. 两腿各自"力矩—角速度—角度"同号 → `τ = −c·ω` 在两腿都是阻尼（安全），`τ = +c·ω` 是负阻尼（助力，需限幅）
2. 左右镜像 → 走路时（左屈右伸）L、R 角度曲线会**同相**；对称性比较用各自的 ROM/步时，不直接比符号
3. **方向已确认（2026-09-22 18:47，用户现场观察）**：两腿"向上抬"= **左腿负方向、右腿正方向**（`T,-x,+x`）。代码里为 `control/policies.py: UP_SIGN`；`ctl up <Nm>` 即两腿同时向上

## 观测到的量程
- 髋角度：本次记录 −108° … +104°（桌面自由摆动）
- 静止噪声：角度 ±0.01°，角速度 ±0.4 °/s

## 官方教程视频（技术支持文档 3.1–3.5，2026-09-17 录制）要点
- 3.1/3.2：VOFA+ 选串口、3000000、FireWater → 开机 → 连接 → 发 `PING` 回 `PONG` → 发 `ENABLE` → 出现 S: 数据；旁白解释 I0 = 时间、I1–I3 = 欧拉角、后面是关节角等，与协议文档一致
- 3.3（穿戴 + 下发力矩）：先穿好、开机、连线；**站着不动时先发力矩**。旁白原话大意：「左边输入 1.0 Nm、右边输入 0.5 Nm；**因为左边和右边的方向是相反的，要两边同向出力，一边要输入负值**」→ 与我们的标定结论（左右镜像）一致；协议示例 `T,1.5,-1.5` 就是"两腿同一物理方向"。VOFA+ 单次发送只持续 100 ms（看门狗），演示里是"发一阵"
- 3.4：穿戴后看 VOFA+ 画图：IMU 在腰上，弯腰时欧拉角变化；抬腿时关节角度变化
- 3.5：结束时发 `DISABLE`（全大写），回 `OK,DISABLE` 后数据停止，然后拔线、关机
- 视频里全程用的是 Windows 笔记本 + USB-A 口（COM3），没有 Mac 直连的情况

## 腿部电机板掉线与恢复（实测 2026-09-22，共 5 次）
- 现象：主板仍以 ~180 Hz 发 S: 帧，但 Ldeg/Rdeg/Ldps/Rdps 精确为 0.000；此时 T 命令无效（没有力）
- 触发：主板重启后（无论是自己重启还是断电重启）腿板不会自动回来；另外设备静止 2–5 分钟后曾多次自行进入此状态（疑似闲置待机）
- **恢复：在机器上做一次开机手势——短按、再长按电源键。** 数据流与串口全程不断，程序自动检测到关节数据非零后恢复（事件 `legs_online`）。不需要拔 USB，也不需要关机
- 腿板上线后 3–10 s 内会有一次 35–40°、1200–1700 °/s 的自检快动（右腿为主）：程序设了 15 s 静默期（不出力、不判定），静默期内手不要放在支架旁；**穿戴前必须等静默期结束**
- 待办：问 Hypershell 闲置待机能否关闭；旧 `--keepalive 60` 脉冲因可能绕过助力策略上限已停用，不能用于展位演示。

## 位置保持（hold）实测
- PID：Kp 0.08 Nm/°，Kd 0.006 Nm/(°/s)，Ki 0.04（限幅 ±0.9 Nm），目标 45 °/s 平滑过渡，总力矩封顶 1.5 Nm，仅桌面档
- 右腿 42° → 1.5°（目标 0）：到位后需 −1.02 Nm 持续抵抗重力/摩擦；右腿 −2° → 22.7°（目标 23）：到位后仅 0.03 Nm，说明该姿态靠机械摩擦自持
- 支架自由悬挂时重力矩约 1 Nm 量级，1.5 Nm 上限足够在桌面上做位置演示
