## 一、总则

**总分 10 分 = 通用维度 6 分 + 赛道专属维度 4 分。**
表头原话：通用维度所有赛道共用；赛道专属维度按参赛赛道四选一；每项按「优秀 / 达标 / 不足」三档打分，档内可取小数一位。

### 分数怎么汇总

1. **至少 3 位评委看过才计分** —— 评委巡展时人不在展位 = 没有分数（硬门槛）
2. 评审环节结束后，评委**统一打分**并上传数据系统留档
3. 你的总分 = 看过你的所有评委的**平均分**
4. 全部项目按分数**由高到低**排名，按排名决定奖项归属；同分以评委上传的原始数据为准
5. **各赛道前 2 名**进 Day4 17:00 主舞台复赛；全场冠军由跨赛道终审产生

> 档与档之间是断开的（例如 1 分项没有 0.85 这一段），所以每项本质是**先判档、再微调**。
> 判成「达标」还是「优秀」，单项差 0.1–0.5 分；8 项累计能差 2 分以上，排名基本就定了。

### 相关流程（同一节）

| 项目 | 规定 |
|---|---|
| 初赛 | Day4 13:00–16:00，约 30 位评委巡展 |
| 单个评委时长 | 约 7 分钟：**4 分钟介绍 + 3 分钟问答** |
| 复赛 | Day4 17:00–18:00，各赛道 Top 2，主舞台，同样 7 分钟，队长抽签定顺序，全员到场 |
| 官方提示 | 展示产品而不只是幻灯片；练电梯演讲；评委走到展位前会**先看官网提交材料**，链接必须逐个验证有效 |

### 已经做完的（对照上一版的性价比排序）

1. ✅ **异常处理接到 Agent 并显示出来** —— 设备事件 → 自动查经验 → 步骤打到终端和页面
2. ⬜ **交付单（带证据、带失败归因）** —— 还没做，是眼下性价比最高的一件
3. ✅ **三层架构** —— 反射 / 直觉 / 经验三层都真的在跑，界面上分三栏摊开
4. ✅ **兜底** —— 数字义体比回放更强：能交互、能注入故障、能挂穿戴者
5. ⬜ **场景与受众一句话** —— 留给人定，见下

### 还需要人拍板的两件事

1. **受众和落地路径一句话**。候选：康复训练（步态不对称时自动降助力，这个我们已经能演）／
   工地搬运／助老。我倾向康复——因为"跛行时置信度掉下来、助力自动降下去"这条链路
   现在就能现场演，别的场景得补东西。
2. **做功预算标定**。桌面档 1.5 J/s 是按"设备放桌上"标的，正常步态实测 1.75 J/s，
   助力会被一直压在 0。改到多少是绑在人身上的安全决定，我没有自己动。

### 展位硬性提醒

- 评委巡展时**全员必须在场**，少于 3 位评委看过 = 没有分数
- 4 分钟讲 + 3 分钟答，先练电梯演讲
- 官网提交材料要在评委来之前就是好的：项目介绍、GitHub 链接可访问、全员信息、赛道
- 五个仓库链接都要能打开：exo-ghost-hypershell / fly-reflex / sim2real-actuator / jev-decide / evomap-genes
