- 独立功能分支、worktree、自动选择的本机端口和独立数据库。
- 产品导航、运动模式页面、来自现有设备服务的实时角度与下发力矩曲线。
- 手动选择助力/锻炼预设，通过原控制入口发送；保留斜坡、限幅、急停与重连静默期。
- CSV 档案收录、来源分类、有效活动时间、左右幅度、分段角速度和指令做功估计。
- 个人偏好保存、参数版本历史、JSON 档案导出。
- 四个基于已完成真实穿戴记录的成长徽章，桌面、仿真、重复、静止或急停记录不增加进度。
- 眼镜照片描述试验：读取指定 Luma 照片目录，用户主动选择 JPEG 后才请求 EvoMap Gateway；照片时间与历史状态明确显示。2026-09-23 已从 E06-0194 真机新拍照片并在产品页得到中文描述。
- 独立 `feat/glasses-demo-GPT` 分支可选运行连续拍照 Demo。页面手动开始、停止，每轮最多 10 张；逐张显示最新画面和 EvoMap 对图像左右较空侧的演示判断，证据不足时显示“无法判断”。

## 使用

集成工作目录启动产品页面：

```sh
uv run python -m product.server --recordings-dir /path/to/exo-ghost/data --device-ws ws://127.0.0.1:8765
```

默认 http://localhost:8110，仅查看，不会自动向设备发送命令。
各功能 worktree 直接运行 `uv run python -m product.server`，端口见 product-branches.md。

要使用产品页面控制设备：先安排真机控制服务切换到集成版本（原控制进程退出并释放串口后再启动），然后产品服务添加 `--control`。
集成 runtime 在状态中标记 body/profile。旧服务仍可看曲线，但缺少真机来源标记时产品控制按钮保持不可用。
启动与重连不会自动恢复产品模式；必须在人确认就绪后重新选择。

## 仍待完成

- 集成分支仍需手动触发拍照并刷新；连续拍照实现位于独立演示分支，尚未合入集成分支。该分支仍不是实时视频，单次拍照约 11 秒，识别另需约 10 秒或更久；模型拥堵时会失败并等待重试。
- 用户将提供真人录音用于电脑扬声器播放。录音尚未收到、验证或接入，当前没有语音提示。清晰模拟通道下的左/右输出也尚未做真机验收；不能用于真实导盲。
- 眼镜环境识别、音频输出与力觉引导尚未进行真机验证；照片描述试验不可作为实际引路。
- 实际人体肌力、省力百分比、疲劳结论、里程和爬升需要额外数据或验证；界面不编造这些结果。
- 跨设备策略自动迁移、康复机构版、保险报告与路线体能预测属于后续产品阶段。
