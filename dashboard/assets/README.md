# Hypershell X Max S 3D asset

`hypershell-x-max-s-textured-parts.glb` was generated with Tripo from official
Hypershell X Max S product images, with permission confirmed by the device owner.
It is a visual approximation, not manufacturer CAD and not a collision or
safety model. The website references show the same model from four angles:

- Front: `https://cdn.shopify.com/s/files/1/0746/6326/4492/files/MaxS_3_290f1d11-2b48-4926-a9a0-82be9fa2d7ad.png?v=1779875781`
- Left: `https://cdn.shopify.com/s/files/1/0746/6326/4492/files/MaxS_5_4ed42d74-0d1a-472e-afdd-4f92c04b20e4.png?v=1779875805`
- Back: `https://cdn.shopify.com/s/files/1/0746/6326/4492/files/MaxS_4_c400b469-8e0f-4048-af88-cb13dae03465.png?v=1779875797`
- Right: `https://cdn.shopify.com/s/files/1/0746/6326/4492/files/MaxS_2_19527cca-caba-41f0-9dba-9cd7419ed263.png?v=1779875789`

The model has 25 mesh nodes. `dashboard/twin-config.json` groups lower leg
parts around two approximate hip pivots. The pivot coordinates and signs are
visual calibration only; they must not be used for physical motion limits or
torque control.
